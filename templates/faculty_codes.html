🏷️ Faculty Short Codes

Each faculty member is assigned a unique short code automatically. This code appears in the timetable to save space.

How codes are generated:
Take the first letter of the first name + first letter of the last name.
Example: Kunal Patil → KP
If two people get the same code, numbers are added: KP1, KP2, etc.
