How it Works

1. Upload Excel — The admin uploads a simple Excel file with faculty, rooms, subjects, and sections.

2. CSP Modelling — Every class/lab session becomes a variable that needs a value (day + period + room + faculty).

3. MRV — The scheduler always picks the session with the fewest valid options first (Minimum Remaining Values).

4. Backtracking — If the scheduler gets stuck, it undoes the last assignment and tries another option.

5. Hard Constraints — No faculty clash, no room clash, no section clash, room capacity respected, labs in labs only.
