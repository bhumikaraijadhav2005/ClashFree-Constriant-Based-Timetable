17. MRV
==================================================

Implement/retain MRV.

MRV means:

Minimum Remaining Values.

For every unscheduled session, calculate how many valid options it currently has.

Choose the session with the FEWEST valid options first.

Example:

Session A → 12 possible choices
Session B → 5 possible choices
Session C → 2 possible choices

MRV chooses:

Session C

first.

Add comments in the scheduler code explaining this clearly.


==================================================
18. BACKTRACKING
==================================================

If the scheduler gets stuck:

1. Undo the previous assignment.
2. Try another valid option.
3. Continue searching.

Example:

Session A assigned Monday 9 AM.

Later Session B has no valid slot.

Backtrack:

Undo Session A.

Try another option for Session A.

Then continue.

The scheduler should not simply fail immediately when one choice causes a dead end.
