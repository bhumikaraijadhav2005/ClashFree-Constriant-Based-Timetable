# ClashFree frontend

This directory contains the React UI and Vite configuration.

```sh
npm install
npm run dev
npm run build
npm run lint
```

The app uses `VITE_API_BASE_URL` at build time when set. Its default is the local Flask API in development and `/api` in production. Backend setup, project structure, and deployment notes are in the root `README.md` and `docs/DEPLOYMENT.md`.
